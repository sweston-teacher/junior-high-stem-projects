Help — How tags work and installing the function

This tool tags owners once and then, every tick, tags non-owners inside each plot with the global restricted tag. Depending on the default mode, it flips player gamemodes accordingly.

Install the generated my_security.mcfunction here:
Documents\Minecraft Education Edition\development_behavior_packs\<Pack>\functions\my_security.mcfunction

Add a minimal manifest.json in your behavior pack (example):

{
  "format_version": 2,
  "header": {
    "name": "ME Security Pack",
    "description": "Security function",
    "uuid": "11111111-1111-4111-8111-111111111111",
    "version": [1, 0, 0],
    "min_engine_version": [1, 16, 0]
  },
  "modules": [
    {
      "type": "data",
      "uuid": "22222222-2222-4222-8222-222222222222",
      "version": [1, 0, 0]
    }
  ]
}

In-game, place one repeating Always Active command block running: /function my_security

Bulk Add Plots

Paste multiple plots in CSV format. One plot per line. Supports comments (lines starting with #).

Format: firstName,lastName,id,label,owners,x,y,z,dx,dy,dz (or old format: id,label,owners,x,y,z,dx,dy,dz)

Example:

# firstName,lastName,id,label,owners,x,y,z,dx,dy,dz
Ava,Smith,plot01,Ava NW,ava123,100,0,200,80,255,80
Jay,Jones,plot02,Jay SE,jaykid,200,0,200,80,255,80
Maya,Brown,plot03,Team 3,"maya,bob",300,0,200,80,255,80
