Classroom Tools

Select one of the visualizers or apps below. These run entirely in the browser, so students can open them from Chromebooks or tablets.

  • Fill Command Visualizer (Relative)

    Slider-based helper for MakeCode fill blocks using relative (~) coordinates.

  • Fill Command Visualizer (Relative + World)

    Includes a toggle for world coordinates with ground height input. Shows both perspectives.

  • Fill Command Visualizer (Extended Range)

    Sliders cover ±64 blocks while the scene stays the same size. Perfect for flat worlds or large plots.

  • Fill Command Visualizer (Safety + Blocks)

    Adds block-count warnings, world height checks, and MakeCode block values.

  • Fill Command Visualizer (Surface Only)

    Version 6 locks Y sliders to the ground so kids stay above the surface.

  • Minecraft Plot Security Builder

    Full-featured dataset editor and command generator for classroom plots.
